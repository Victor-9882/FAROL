Como os índices são calculados
  • Presença na sede: 2 · presença − 1, a mesma conta do protótipo do PEI. A presença é a do ciclo, com falta justificada contando como presença (RN002): 0% vira −1, 50% vira 0 e 100% vira +1.
  • Notas nos simulados: limitar(z / 2, −1, +1), com z = Δ / σ. Δ é a nota TRI média do ciclo menos a do último simulado em que o aluno foi avaliado (RN008), e σ é o desvio-padrão dos Δ do curso no ciclo{% if quadro.sigma %} ({{ quadro.sigma|floatformat:1 }} pontos){% endif %}. ±1 equivale a dois desvios.
  • O zero de cada eixo separa os grupos. Não há limiar novo: os limiares de alerta (Regras) não mudam os grupos.
